## 🎧 Overview

**Immersive 3D Audio** upgrades conventional mobile audio to a dynamic, multi-directional spatial listening stage. Designed with an ultra-minimalist, pure-black AMOLED interface for zero-distraction control and battery efficiency.

### ✨ Key Features

* **3D Spatial Virtualizer:** Simulates directional soundscapes, allowing precise audio pinpointing in music, media, and games.
* **Dynamic Spatial Bass:** Enhances lower-end frequencies dynamically without muddying mid-range vocals.
* **Sub-Bass Boost:** Low-frequency impact tuning tailored for external headphones and sound systems.
* **Device Speaker Optimization:** Dedicated tuning toggle to drive phone built-in loudspeakers safely and clearly.
* **AMOLED True-Black UI:** Minimalist pure-black canvas with cyber-cyan high-contrast accents.

## 📥 Installation

1. Grab the latest APK from the [Releases](../../releases) tab.
2. If you have an older version installed, uninstall it first to avoid signature conflict errors.
3. Install the APK and grant required audio/notification permissions.
4. Adjust the sliders to match your preferred listening stage.
